# Roadmap — Хронос (редизайн yunusmi/time-tracker)

## Реализовано в прототипе (v2)
1. Командная палитра (Cmd/Ctrl+K): запуск таймера по тексту, старт по задаче, создание задачи, навигация, тема
2. Горячие клавиши: S стоп/продолжить, N новая задача, F фокус-режим, T тема, 1–6 экраны, ? справка, Esc
3. «Продолжить» — чипы недавних работ, старт в один клик
4. Таймлайн дня (08:00–20:00) с цветами проектов, живой сегмент
5. Фокус-режим — полноэкранный таймер (F / кнопка ⛶)
6. Редактирование времени записи инлайн (клик по интервалу)
7. Pomodoro → трекер: фокус-сессии автоматически создают записи времени (переключатель)
8. Серия целей (streak) + heatmap 14 дней в отчётах
9. Напоминания (настройки, демо-переключатели)
10. Экран «Проекты»: создание с цветом, переименование инлайн, архив, статистика за неделю
11. Команда: роли (владелец/админ/участник), приглашения по email и ссылке, отзыв инвайтов
12. Настройки аккаунта: имя, email, верификация почты, смена пароля
13. Роли и права: владелец/админ/участник + демо-переключатель «смотреть как роль»; участник видит только свои задачи/отчёты, не видит «Проекты», не приглашает
14. Назначение задач: админ ставит задачи сотрудникам, фильтр «Все сотрудники/Мои»; отчёты по участникам для админа
15. Дизайн писем: Emails.dc.html — верификация почты + приглашение в команду
16. Таймшиты: участник отправляет неделю на проверку, админ утверждает/возвращает с комментарием
17. Аудит-лог действий (для админа, в «Команде»)
18. Ставки ₽/ч по проектам + billable-флаг у записей + суммы в отчётах
19. Дедлайны и приоритеты задач + баннер о просрочке
20. Интеграции: Google Calendar, Slack, Telegram (демо-подключение)
21. «Мои задачи на сегодня» в Трекере (просрочено/дедлайн сегодня/в работе, старт в клик)
22. «Забытый таймер» (баннер после 4ч) + авто-стоп в конце дня (настройка)
23. Комментарии к записям времени
24. Центр уведомлений (правки админа, утверждение таймшита, новые задачи)
25. «Не беспокоить» в команде во время фокус-сессии
26. Дашборд команды для админа: кто трекает, недобор, перегруз
27. Массовое утверждение таймшитов
28. Бюджет часов на проект (недельный, с предупреждением)
29. Экспорт по периоду (день/неделя/месяц) и проекту
30. Права: ставки/бюджеты видны только owner/admin; утверждённая неделя блокирует записи; роль «менеджер проекта» (задачи и отчёты своего проекта, без денег)
31. Onboarding: тур из 3 шагов + чек-лист «Первые шаги» в Трекере
32. Drag-редактирование записей на таймлайне (тянуть края, шаг 5 мин)
33. Undo при удалении записи/задачи («Отменить» в тосте)
34. История записей в поиске ⌘K
35. Мобильный режим: сайдбар-шторка (☰), колонки в одну
36. Календарь-вид недели в отчётах (блоки записей по часам)
37. Инвойс из billable-часов (превью счёта + PDF демо)
38. Шаблоны задач (чипы + «сохранить как шаблон»)
39. Индикатор оффлайна (записи локально, синк позже)
40. Публичная ссылка на отчёт (скрыть суммы/имена)
41. Роль «Клиент» — только отчёт своего проекта, read-only
42. 2FA для владельца/админов (QR + код, демо)
43. Стендап-отчёт: авто-генерация текста «отчёт за вчера / план на сегодня» (или сегодня/завтра) из записей и задач, ссылки на задачи, «код-ревью и созвоны», отработано/осталось часов, копирование в один клик
44. Стендап-отчёт 2.0: редактируемый текст, свой шаблон (приветствие/активности/подпись), AI-сводка по задачам, отправка в Slack/Telegram, авто-отправка в 10:00
45. Отчёт для клиента (текст) за неделю по проекту с часами и суммой
46. Авто-сводка недели прикладывается к таймшиту при отправке
47. Сводка команды за вчера для админа (один текст по всем)
48. Release notes из задач «Готово» за неделю
49. Разрезание записи пополам (✂ в редакторе записи)
50. Округление времени до 15/30 мин для клиентских отчётов и счетов (Настройки)
51. Десктоп-агент (концепт): предложение записи из активности приложений
52. Таймер в заголовке вкладки браузера («▶ 1:23 · Хронос»)
53. Оценка vs факт: процент у задач с цветом (зелёный/жёлтый/красный)
54. Канбан-вид задач (Список/Канбан, перенос стрелками между колонками)
55. Загрузка на неделю: открытые задачи vs норма по каждому сотруднику (Команда)
56. Персональные ставки сотрудников (перекрывают ставку проекта)
57. Отпуска: статус в команде, исключение из недобора
58. Норма часов в день (Настройки)
59. API-ключ + Webhook URL (Настройки)
60. Экспорт всех данных (GDPR) и удаление аккаунта
61. Ранее: цели дня, idle-detection, проекты, статусы, отчёты, команда, 2 темы

## Требует бэкенда (следующий этап)
- Workspaces/команды: приглашения, роли, live-статус участников
- Idle detection на сервере (heartbeat) + вычет простоя
- Push/браузерные уведомления
- Проекты и оценки задач в схеме БД (projects table, task.estimate)
- エндпоинты недельной аналитики (сейчас можно собрать по /time-entries?date=)


## Этап 2 — мультитенантность (в прототипе)
- Регистрация владельца: имя компании → создание workspace
- Несколько компаний/workspace на аккаунт, переключатель
- Отделы внутри компании, привязка сотрудников и проектов
- Изоляция данных по workspace на уровне БД (workspace_id везде)
- Онбординг: компания → пригласить сотрудников → первый проект

Сделано в прототипе: переключатель компаний в сайдбаре, мастер «Создать компанию» (название → отделы → приглашения), отделы с фильтром в «Команде». База знаний: Knowledge Base.dc.html.

## Этап 3 — вход и онбординг (в прототипе)
- Auth Flows.dc.html: логин с 2FA, регистрация с выбором «команда/для себя», мастер компании, принятие инвайта (новый/существующий пользователь), сброс пароля
- Public Report.dc.html: публичная страница отчёта для клиента
- Интерактивный тур по ролям в кабинете: карточка-гид переключает реальные экраны, финал с базой знаний

## Этап 3+ — активация (в прототипе)
- SSO Google/Microsoft + magic link + капча после 2 неудач
- Сессии и устройства с «выйти везде»
- Демо-данные одним кликом, импорт Toggl/Clockify/Harvest/CSV
- Чек-лист владельца с прогрессом, welcome-письмо

## Финальный батч (в прототипе)
- Лендинг (бесплатный продукт, без тарифов)
- Настройки уведомлений (5 переключателей)
- Профиль сотрудника из «Команды» (+ отметить отпуск)
- Единый SVG-логотип во всех страницах и письмах
- Письма: назначение задачи + дайджест недели (всего 7)

## Клиентская петля и polish (в прототипе)
- Редактор вех (Проекты) ↔ вехи у клиента
- Вопросы по отчёту (тред клиент↔менеджер)
- Групповые действия над задачами
- ⌘K: люди/проекты/настройки
- Тема «как в системе», звук+уведомление Pomodoro

## Оплата и уведомления (в прототипе)
- Профиль сотрудника: почасовая/оклад + значение (admin+)
- Возврат таймшита только с причиной (чипы + текст) → письмо, плашка в кабинете, колокольчик, аудит
- Матрица уведомлений Email/Пуш/В кабинете по каждому событию + запрос разрешения браузера на Web Push

## Валюта и уведомления (в прототипе)
- Валюта компании: RUB/USD/EUR/KZT/UZS — применяется во всех суммах
- Экран «Уведомления» для всех ролей: фильтры, типы, каналы, действия, счётчик непрочитанных

## Полировка перед разработкой
- Пустые состояния на всех экранах (Трекер/Задачи/Проекты/Отчёты/Команда)
- Убраны: демо-переключатель ролей (помечен как прототипный), десктоп-агент
- Логотип, название и цвет компании — Настройки → Компания (admin+)
- В ТЗ добавлен раздел «обязательно при реализации»: skeleton, подтверждения, пагинация, ошибки сети/оффлайн
